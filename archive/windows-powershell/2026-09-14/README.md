# Archived Dell/Windows CAAB workbook exporter

`export_caab_workbook.ps1` is retained only to document the former Excel COM
workflow. The active Mac implementation is `tools/export_caab_workbook.sh`,
which uses the Codex Desktop bundled LibreOffice/soffice runtime and produced a
63,302-line UTF-8 CSV from the restored CAAB workbook on 2026-09-14.

Do not restore the PowerShell file as an active dependency.
